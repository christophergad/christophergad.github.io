# Portfolio GitHub migration

This branch is the isolated migration workspace for the existing Wix portfolio.

## Goals
- Preserve the approved desktop portfolio design.
- Convert Wix iframe navigation to normal static-site navigation.
- Replace the Wix Project Image Viewer with a standalone lightbox.
- Preserve gallery previous/next navigation.
- Keep current Wix-hosted images during the first migration pass.
- Rebuild responsive/mobile behavior after desktop parity is verified.
- Keep the current Wix site untouched until the GitHub version is approved.

## Migration order
1. Shared standalone navigation + lightbox.
2. Landing page + Gordon Freedom proof of concept.
3. Remaining project pages.
4. Watch Dogs hub and all case-study pages.
5. Responsive/mobile polish.
6. Move media assets off Wix.
7. Enable GitHub Pages on main after final approval.
8. Point the custom domain only after validation.

Nothing on this branch changes the live Wix site.
